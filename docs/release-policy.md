# Release Policy

The Git repository contains source code, tests, protocols, documentation, and
small reviewed summaries. It does not contain raw ECG data, window caches,
per-record predictions, private logs, or unapproved model weights.

Each public evidence item must include its evidence class, source experiment,
configuration identifier, and SHA-256 hash where applicable. Failed attempts
remain disclosed and are never silently replaced by later successful artifacts.

GitHub Releases may contain small, explicitly approved artifacts. A GitHub
Release is public; it is not a mechanism for private storage. Restricted
research archives must use an institution-approved private location or a later
versioned DOI deposit.
